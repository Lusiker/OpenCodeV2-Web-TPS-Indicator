安装用户脚本 下载浏览器扩展

用户脚本需要先安装 Tampermonkey 或 Violentmonkey。安装后刷新 OpenCode 会话页即可。

扩展安装：解压下载的 zip，打开 chrome://extensions，启用开发者模式， 点击「加载已解压的扩展程序」，选择解压后的 extension 目录。 加载完成后刷新已经打开的 OpenCode 标签页。

原生 GUI 插件位于 ../dist/gui-experimental.cjs，适用于 OpenCode Desktop 2.2.0 及以上版本。
